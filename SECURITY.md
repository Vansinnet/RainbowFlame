# Security Policy

## Supported Version

Security fixes are considered only for the latest official RainbowFlame release
and its explicitly supported Darktide build. Older releases and unlisted game
builds are unsupported.

## Reporting a Vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's private
vulnerability reporting feature for this repository if it is available. If it is
not available, contact Vansinnet privately through the contact method shown on
the repository owner's GitHub profile.

Include the RainbowFlame release, Darktide build, impact, reproduction steps, and
whether the issue has been disclosed elsewhere. Do not include account secrets,
personal data, copyrighted game files, or exploit code beyond what is necessary
to explain the report.

Submitting a report does not grant permission to access other systems, distribute
RainbowFlame, or violate the [LICENSE](LICENSE). Please allow time for assessment
before any coordinated disclosure date is discussed.
