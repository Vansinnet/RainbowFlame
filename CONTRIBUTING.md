# Contributing to RainbowFlame

Bug reports and feature requests are welcome through this repository's issue
tracker. Before opening an issue, check existing issues and include enough detail
to reproduce or assess the request.

RainbowFlame is proprietary, source-visible software. Public visibility of the
source does not grant permission to modify or redistribute it.

Code, asset, documentation, translation, and other contributions are accepted
only after Vansinnet has explicitly agreed in writing to the contribution and
its assignment terms. Do not submit unsolicited code, patches, pull requests,
assets, or derivative works. Opening an issue does not authorize implementation
or create an agreement to accept a contribution.

If a contribution is invited, the contributor must agree in writing to assign
the contribution and all transferable intellectual-property rights in it to
Vansinnet, and must confirm that the work is original and can lawfully be
assigned. Any different terms must be agreed in writing before work is submitted.
